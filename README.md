# IDS Dashboard — Setup

Two parts: the FastAPI backend (`main.py`, `live_ids.py`) and a React app in `dashboard/`.

## What changed in the existing files

**`main.py`**

* Added CORS so the dashboard can connect to the backend on a different port.
* Added in-memory `STATE` that keeps track of total flows, flagged flows, attack classes, recent traffic history, and the last 50 alerts.
* Added these endpoints:

  * `GET /stats` — returns the dashboard statistics.
  * `GET /evidence` — shows archived PCAPs with attack type, confidence, and IP information.
  * `GET /evidence/download/{filename}` — downloads an archived PCAP.
  * `GET /evidence/features/{filename}` — returns the information saved with an archived PCAP.
* `EVIDENCE_DIR` uses the local `evidence` folder by default and can also be changed using the `IDS_EVIDENCE_DIR` environment variable.

**`live_ids.py`**

* When a threat PCAP is saved, a JSON file is also saved with it. This contains the attack distribution, confidence, and IP information used by the dashboard.
* `EVIDENCE_DIR` can use the same `IDS_EVIDENCE_DIR` environment variable as `main.py`.

Nothing else about the model, feature mapping, or CICFlowMeter integration was changed.

## CICFlowMeter setup

**CICFlowMeter is required for live flow detection.**

If you want to use the **START CAPTURE** / live detection feature, you need to have CICFlowMeter installed and properly configured on your computer.

The live detection flow is:

**Network traffic → CICFlowMeter → Flow CSV → IDS model → Dashboard**

Without CICFlowMeter, the dashboard can still be used with the available CSV prediction functionality, but **live network flow detection will not work**.

Make sure the CICFlowMeter path in `live_ids.py` is correct for your own computer.

If `main.py` and `live_ids.py` are using different evidence folders, set the same folder using:

```bash
set IDS_EVIDENCE_DIR=C:\CICFlowMeter-master\CICFlowMeter-master\evidence
```

Run this before starting the backend and live detection.

## Running it

### Backend

Open a terminal in the project folder:

```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

The backend will run on:

```text
http://127.0.0.1:8000
```

### Dashboard

Open another terminal:

```bash
cd dashboard
npm install
npm run dev
```

The dashboard will open on:

```text
http://localhost:5173
```

The dashboard connects to the FastAPI backend through the Vite proxy.

## Live detection

For live detection:

1. Install and configure CICFlowMeter.
2. Make sure the CICFlowMeter path in `live_ids.py` is correct.
3. Start the FastAPI backend.
4. Open the dashboard.
5. Click **START CAPTURE**.

The dashboard will receive the flows generated by CICFlowMeter and send them through the IDS model for detection.

The traffic chart, threat feed, alert overview, and forensic archive update automatically.

## CSV detection

The backend can also process CSV flow data through the prediction endpoint.

The model uses the CIC-IDS2017 feature format and predicts the traffic class.

* Normal
* DoS

* Web Attack
* PortScan
* Bot
* Brute Force

## Important notes

* Dashboard statistics are stored in memory and reset when the backend is restarted.
* The dashboard currently uses polling to update the data.
* Authentication has not been added, so this setup should not be exposed directly to the public internet.
* `flood.py` is a separate traffic testing script and is not connected to the dashboard.
* PCAP files and CSV files are excluded from Git using `.gitignore`.
* The CICFlowMeter installation is not included in this repository. Anyone setting up the project for live detection needs to install and configure CICFlowMeter separately.
